# Karuppasamy Portfolio

Personal portfolio of **S. Karuppasamy** — Data Analytics fresher, B.Sc. Computer Science (2026).

Built with Flask, Bootstrap 5 and Font Awesome. Deploys to Vercel.

## Run locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Customize
- Photo: put `profile.jpg` in `static/Images/` (falls back to initials if missing)
- Resume: `static/files/Karuppasamy_Resume.pdf`
- LinkedIn: replace the `#` link in `templates/base.html` / `index.html`
